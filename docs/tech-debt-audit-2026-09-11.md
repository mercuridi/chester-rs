**How to read the estimates.** Ease is an effort band: E1 easy (roughly half a day or less), E2 small (roughly 1–2 days), E3 moderate (roughly 3–5 days), E4 hard (roughly 1–2 weeks), E5 very hard (longer). These are planning estimates for someone familiar with the repository, including appropriate tests, not commitments.

I/M are separate ordinal simplification benefits, each 1–5: I = less raw implementation and repeated work; M = fewer concepts, invariants, and failure states to understand. **Leverage = (I + M) / effort score**. A score of 5.0 is more simplification per unit effort than 1.5; it is not measured financial ROI, a speedup, or a literal fivefold code reduction. The future-complexity column describes the maintenance capacity the fix should free. Benefits overlap, so do not sum scores or budget savings across rows.
